Imperial's Computing (BEng/MEng) first year covers eight core modules, roughly split between computer science, math, and hands-on practical work:

**Computer science core**
- *Introduction to Computer Systems* — how a computer works from the ground up: digital logic, an introduction to a low-level/systems language (typically C), and how software runs on hardware.
- *Introduction to Computer Architecture* — CPU design, instruction sets, pipelining, memory hierarchy — the hardware side underlying Computer Systems.
- *Introduction to Databases* — relational model, SQL, normalisation, basic database design.
- *Graphs and Algorithms* — core data structures (lists, trees, graphs) and algorithmic techniques (sorting, searching, graph traversal, complexity analysis).
- *Computing Practical 1* — the applied programming thread: builds software engineering skill (likely Java and/or Python) through weekly coursework, alongside the theory modules.

**Mathematics core**
- *Discrete Mathematics, Logic and Reasoning* — propositional/predicate logic, proof techniques, set theory, combinatorics — the formal reasoning toolkit CS relies on.
- *Calculus* — standard engineering-flavoured calculus: limits, differentiation, integration, series.
- *Linear Algebra* — vectors, matrices, linear transformations, eigenvalues — foundational for later ML/graphics/numerics work.

That's the whole first year: no specialisation yet — it's meant to give everyone the same base in systems, theory, and applied programming before branching out in year 2.
