# Global rules

- Always apply the personal skill `standard-technical-coding-practices`
  (~/.claude/skills/standard-technical-coding-practices/SKILL.md) to every
  coding or technical task, in every project, even trivial ones.
- Always apply the personal skill `standard-technical-english`
  (~/.claude/skills/standard-technical-english/SKILL.md) to every reply,
  in every project. It is the authority on prose shape.
- When a message arrives whose first line starts with `SWARM HANDOFF:`,
  or the user asks for a swarm handoff, apply the personal skill
  `standard-technical-handoff-swarm`
  (~/.claude/skills/standard-technical-handoff-swarm/SKILL.md).
