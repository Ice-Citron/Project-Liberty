Density: area is probability

A continuous X can land anywhere on a line. So no single value can hold any probability. Probability lives in areas under a curve f. The height of f is a density: probability per unit of x.

1 · U(0, 0.25) is a valid pdf. How tall is it?
4. The width is 0.25. So the height must be 4 for an area of 1. A density may exceed 1.
2 · X ~ Exp(1). Which is larger: P(X ≤ 1) or P(X < 1)?
Neither. Both equal 1 − e^(−1) ≈ 0.632. The single point x = 1 adds zero area.
3 · f(x) = c·x² on [0, 1]. Which c makes it a pdf?
c = 3. The area is c/3. Set c/3 = 1. Slide c to 3 and watch the verdict change.
4 · Where does the cdf of N(0, 1) rise fastest?
At x = 0. The slope of F is f. The density peaks at 0 with f(0) = 1/√(2π) ≈ 0.399.
5 · Pareto with k = 1 and α = 2. What is P(X > 10)?
0.01. P(X > x) = (k/x)^α = (1/10)² = 0.01. An Exponential with the same mean gives only about 0.0067.

Density and the cdf
F(x) = P(X ≤ x) = ∫ from −∞ to x of f(u) du f(x) = d/dx F(x) = F′(x)
The slide Probability Density Function defines f through F. The slide pdf as the Derivative of the cdf turns it round. Integrate f to get F. Differentiate F to get f.
Interval probabilities
P(a < X ≤ b) = P(X ≤ b) − P(X ≤ a) = F(b) − F(a) = ∫ from a to b of f(x) dx
Everything up to b minus everything up to a leaves the part in between. That part is the area under f from a to b.
Why one point has probability 0
{X = b} lies inside {b − h < X ≤ b} for every h > 0 P(X = b) ≤ F(b) − F(b − h) → 0 as h → 0 so P(X = b) = 0 and P(X ≤ b) = P(X < b) countable set: P(X ∈ {x₁, x₂, …}) = 0 + 0 + … = 0
F is continuous. So the thin strips that end at b hold less and less. Countably many zeros still add up to 0. So the support of a continuous X must be uncountable.
Density is probability per unit of x
P(x ≤ X < x + h) = F(x + h) − F(x) ≈ F′(x)·h = f(x)·h for small h f(x) = lim as h → 0 of P(x ≤ X < x + h) / h
A density of 2 puts about 0.02 of probability in a strip of width 0.01. So f(x) may exceed 1. Only areas must stay at or below 1.

Two worked answers
Find c for f(x) = c x² on [0, 1]: ∫ from 0 to 1 of c x² dx = c [x³/3] from 0 to 1 = c/3 c/3 = 1 ⇒ c = 3
Q&A, Pareto: f(x) = α k^α / x^(α+1) for x ≥ k F(x) = ∫ from k to x of α k^α u^(−α−1) du = [−k^α u^(−α)] from k to x = 1 − (k/x)^α P(X > x) = 1 − F(x) = (k/x)^α
The Pareto tail (k/x)^α shrinks like a power of x. An Exponential tail e^(−λx) shrinks much faster. So the Pareto tail is called heavy.

The Essence
Area is probability. P(a < X ≤ b) is the area under f from a to b. The height of f is not a probability.
Height is density. f(x) is probability per unit of x. A thin strip of width h holds about f(x)·h.
Points are free. A single point has zero width. So it has zero area and P(X = x) = 0.
F collects area and f is its slope. F(x) adds up area from the left. The steepness of F at x is f(x).
Two rules make a pdf. f(x) ≥ 0 everywhere and a total area of 1. A height above 1 breaks no rule.
Σ becomes ∫. Slice the line into strips of width h. Each strip acts like a pmf bar. Shrink h and the sum becomes an integral.

Honest caveats
Not every random variable has a pdf. A wait that is exactly 0 with probability 0.3 gives F a jump. The slides call the pdf case absolutely continuous.
f(x)·h needs f to be smooth near x. At a jump of f the rectangle uses the height on one side only.
A histogram is noisy. Narrow bins catch few samples. So they need many samples to settle.
The value of f at one point does not matter. A change of f at a single x changes no area. So a < x < b and a ≤ x ≤ b give the same Uniform.
The Pareto mean is finite only for α > 1. It equals αk/(α − 1). This is a standard result and not on the slides.
The Normal cdf here comes from a series. Chapter 4 shows the table method from the slides.
