Uniform and Exponential: flat, then memoryless

Two shapes do most of the work. The Uniform spreads probability flat across an interval. The Exponential waits for an event with the same risk at every moment. That constant risk gives it no memory.

1 · U(0, 0.5) has height 2. Is a density above 1 a problem?
No. A density is not a probability. Only area is probability. Here the area is 2 × 0.5 = 1.
2 · Take U(2, 8). Guess σ² before you compute.
σ² = 3. The width is 6. So σ² = 6²/12 = 36/12 = 3 and σ ≈ 1.732.
3 · Exp(0.5) has a mean wait of 2. You already waited 3. What is the mean wait still to come?
Still 2. The past wait carries no information. The wait ahead is again Exp(0.5).
4 · Exp(λ): does the median sit above or below the mean?
Below. The median is ln 2/λ ≈ 0.6931/λ. The mean is 1/λ. The long right tail pulls the mean up.
5 · Calls arrive at rate 2 per hour. What is the chance of no call in the next 30 minutes?
About 0.368. The count in half an hour is Poi(2 × 0.5) = Poi(1). So P(no call) = e^(−1) ≈ 0.368. This is also P(first wait > 0.5).

Uniform U(a, b)
f(x) = 1/(b − a) for a < x < b = 0 otherwise F(x) = 0 for x ≤ a = (x − a)/(b − a) for a < x < b = 1 for x ≥ b
The height must make the area 1. The width is b − a. So the height is 1/(b − a).
From U(0, 1) to U(a, b)
X ~ U(0, 1), Y = a + (b − a)X F_Y(y) = P(Y ≤ y) = P(a + (b − a)X ≤ y) = P(X ≤ (y − a)/(b − a)) as b − a > 0 = F_X((y − a)/(b − a)) = (y − a)/(b − a)
The event does not change. Only the ruler changes. So the probability stays the same.
Why the 12
U(0, 1): E(X) = ∫₀¹ x dx = 1/2 E(X²) = ∫₀¹ x² dx = 1/3 σ² = 1/3 − (1/2)² = 1/12 U(a, b) = a + (b − a)X: μ = a + (b − a)/2 = (a + b)/2 σ² = (b − a)² × 1/12 Direct route, as on the slide: E(X) = ∫ₐᵇ x/(b − a) dx = (b² − a²)/(2(b − a)) = (a + b)/2 E(X²) = ∫ₐᵇ x²/(b − a) dx = (b³ − a³)/(3(b − a)) = (a² + ab + b²)/3 σ² = (a² + ab + b²)/3 − (a + b)²/4 = (b − a)²/12
The 3 comes from the integral of x². The 4 comes from the square of the mean ½. Their difference is 1/3 − 1/4 = 1/12. The stretch step uses Var(aX + b) = a²Var(X).
Exponential Exp(λ)
f(x) = λe^(−λx), x ≥ 0 F(x) = ∫₀ˣ λe^(−λt) dt = [−e^(−λt)]₀ˣ = 1 − e^(−λx) P(X > x) = e^(−λx) P(c < X ≤ d) = F(d) − F(c) = e^(−λc) − e^(−λd)
Mean and variance, by parts
∫ u dv = uv − ∫ v du u = x, dv = λe^(−λx) dx du = dx, v = −e^(−λx) E(X) = [−x e^(−λx)]₀^∞ + ∫₀^∞ e^(−λx) dx = 0 + 1/λ E(X²) = [−x² e^(−λx)]₀^∞ + ∫₀^∞ 2x e^(−λx) dx = 0 + (2/λ) E(X) = 2/λ² σ² = 2/λ² − 1/λ² = 1/λ² median m: 1 − e^(−λm) = 1/2 so m = ln 2/λ ≈ 0.6931/λ
The boundary terms vanish. At 0 the factor x is 0. At ∞ the exponential decays faster than any power of x grows.
No memory
P(X > s + x | X > s) = P(X > s + x and X > s) / P(X > s) = P(X > s + x) / P(X > s) = e^(−λ(s + x)) / e^(−λs) = e^(−λx) = P(X > x)
The event X > s + x already contains X > s. So the joint event is just X > s + x.
Slots: the continuous Geometric
slot width h, chance per slot p = λh K ~ Geometric(λh), the wait is Kh P(Kh > x) = (1 − λh)^(x/h), x a multiple of h ln of it = (x/h) ln(1 − λh) ≈ (x/h)(−λh) = −λx so (1 − λh)^(x/h) → e^(−λx) as h → 0 E(Kh) = h × 1/(λh) = 1/λ, at every h Var(Kh) = h²(1 − λh)/(λh)² = (1 − λh)/λ² → 1/λ²
This is a standard result. It is not on the L04 slides. It joins the L03 Geometric to Exp(λ).
Link with Poisson
N_x ~ Poi(λx): the count of events in [0, x] X = the time of the first event X > x ⇔ no event in [0, x] ⇔ N_x = 0 P(X > x) = P(N_x = 0) = (λx)⁰ e^(−λx) / 0! = e^(−λx) So X ~ Exp(λ).
The same argument works for every later gap. So all gaps are Exp(λ).

The Essence
Flat means length. For U(a, b) the chance of an interval is its length over b − a.
One uniform makes them all. Y = a + (b − a)X turns U(0, 1) into U(a, b).
The 12 is 1/3 − 1/4. Stretch by b − a and the variance grows by (b − a)².
Exponential means constant risk. It is a Geometric with infinitely thin slots.
No memory. A wait of s tells you nothing about the wait ahead.
Poisson counts, exponential gaps. No event in [0, x] is the same event as a first wait above x.
Mean above median. The mean is 1/λ. The median is ln 2/λ. The skewness is exactly 2, the lower limit of the Geometric on the skewness page.
Mental-picture checklist
Honest caveats
Rate or mean? Some books write Exp(θ) with mean θ. The lecture uses the rate λ. So the mean is 1/λ.
Constant risk is an assumption. Parts that wear out fail more often with age. The slide calls no memory "not always desirable".
Open or closed ends do not matter. P(X = a) = 0 for a continuous X. So (a, b) and [a, b] give the same probabilities.
The slot model is a standard result. It is not on the slides. The same goes for the integration by parts and the median.
Simulations wobble. A histogram of a few thousand gaps never matches the curve exactly.
