The mgf: every moment on one washing line

E[X], E[X²] and E[X³] each need their own sum or integral. The moment generating function M(t) = E[e^(tX)] stores all of them in one curve. Its slope at t = 0 is the mean. Its curvature at t = 0 is E[X²].

Read the question. Commit to an answer. Then open the card and check.
1 · What is M(0) for any distribution?
Always 1. At t = 0 every weight e^(0·x) equals 1. So M(0) = E[1] = 1. Every mgf passes through the point (0, 1).
2 · X ~ Exp(1). Is M(1.2) finite?
No. The weight e^(1.2x) grows faster than e^(−x) shrinks. So the tilted curve rises for ever. Its area is infinite. Exp(λ) has an mgf only for t < λ.
3 · X ~ Poisson(3). What are M′(0) and M″(0)?
M′(0) = 3 and M″(0) = 12. The slope gives E[X] = λ. The curvature gives E[X²] = λ + λ². So σ² = 12 − 9 = 3.
4 · X₁ ~ Poisson(2) and X₂ ~ Poisson(3) are independent. What is X₁ + X₂?
Poisson(5). Multiply the mgfs: e^(2(e^t − 1)) × e^(3(e^t − 1)) = e^(5(e^t − 1)). That is the Poisson(5) mgf. The uniqueness theorem does the rest.
5 · Roll one die and set Z₁ = Z₂ = the result. Is E[Z₁Z₂] = 3.5²?
No. E[Z₁Z₂] = E[Z₁²] = 91/6 ≈ 15.17. But 3.5² = 12.25. The product rule needs independence.
Each number is rounded to 4 significant figures. The sums use full precision. So a last digit can differ by 1.
The definition
Continuous X: M_X(t) = E(e^(tX)) = ∫ e^(tx) f_X(x) dx Discrete X: M_X(t) = E(e^(tX)) = Σ e^(t xᵢ) p(xᵢ)
M is a function of t, not of x. Each t gives one weighted average of X. The slide Moment Generating Function gives both forms.
Why derivatives give moments
e^(tX) = 1 + tX + t²X²/2! + t³X³/3! + … M(t) = 1 + t E[X] + t² E[X²]/2! + t³ E[X³]/3! + … M′(t) = E[X e^(tX)] → M′(0) = E[X] M″(t) = E[X² e^(tX)] → M″(0) = E[X²] M⁽ⁿ⁾(0) = E[Xⁿ] σ² = M″(0) − M′(0)²
Each derivative brings down one more factor X. Then t = 0 removes the weight. The slide Properties of the mgf states this rule. It assumes we may differentiate inside the integral.
Uniqueness
If M_X(t) = M_Y(t) then X and Y have the same cdf. The slide Properties of the mgf states this theorem. The two mgfs must agree on an open interval around 0. So an mgf is a fingerprint. Recognise it and you know the distribution.
The family table · standard results
Poisson: Σ e^(tx) e^(−λ) λ^x / x! = e^(−λ) Σ (λe^t)^x / x! = e^(−λ) e^(λe^t) = e^(λ(e^t − 1)) Exponential, only for t < λ: ∫₀^∞ e^(tx) λe^(−λx) dx = λ ∫₀^∞ e^(−(λ − t)x) dx = λ / (λ − t) Normal, complete the square: tx − (x − μ)²/(2σ²) = μt + σ²t²/2 − (x − μ − σ²t)²/(2σ²) The last term integrates to σ√(2π). So M(t) = e^(μt + σ²t²/2).

The characteristic function
φ_X(t) = M_X(it) = ∫ e^(itx) f_X(x) dx |e^(itx)| = 1, so |φ_X(t)| ≤ ∫ f_X(x) dx = 1 E[Xⁿ] = i^(−n) φ⁽ⁿ⁾(0)
The mgf integral can diverge. The Lognormal is an example. The characteristic function always exists. Its weight only turns in the complex plane. It never grows. The slide Characteristic function gives these lines.
Products and sums
Z₁, Z₂ independent: E[Z₁Z₂] = E[Z₁] E[Z₂] M_(Z₁+Z₂)(t) = E(e^(t(Z₁+Z₂))) = E(e^(tZ₁) e^(tZ₂)) = E(e^(tZ₁)) E(e^(tZ₂)) = M_Z₁(t) M_Z₂(t) Sₙ = X₁ + … + Xₙ: M_Sₙ(t) = Π M_Xⱼ(t)
The second line uses the product rule for e^(tZ₁) and e^(tZ₂). Those are independent because Z₁ and Z₂ are. The slides Product of Independent Random Variables and Sum of Independent Random Variables give these rules.
Poisson(λ₁) + Poisson(λ₂), independent: e^(λ₁(e^t − 1)) × e^(λ₂(e^t − 1)) = e^((λ₁ + λ₂)(e^t − 1)) → Poisson(λ₁ + λ₂) by uniqueness n independent Bernoulli(p): (1 − p + pe^t) × … × (1 − p + pe^t) = (1 − p + pe^t)ⁿ → Binomial(n, p) by uniqueness

The Essence
One curve, every moment. M(t) = 1 + tE[X] + t²E[X²]/2! + … . Each power of t carries one moment.
Slope and curvature at 0. M′(0) = E[X] and M″(0) = E[X²]. So σ² = M″(0) − M′(0)².
The tilt picture. M(t) is the area under e^(tx)·f(x). Positive t lifts the right tail. Negative t lifts the left tail.
It may not exist. A heavy tail makes the tilted area infinite. Exp(λ) allows only t < λ. The Lognormal allows no t > 0.
Sums become products. Independent parts multiply their mgfs. Uniqueness then names the distribution of the sum.
Products need independence. E[Z₁Z₂] = E[Z₁]E[Z₂] holds for independent Z₁ and Z₂. Dependence breaks it.

Honest caveats
The mgf must exist near 0. The moment rule and uniqueness need M(t) finite on an open interval around 0.
Moments alone may not pin down a distribution. The Lognormal is the classic case. Other distributions share all of its moments. This is a standard result.
The Uniform formula reads 0/0 at t = 0. Its limit is 1, as for every mgf.
