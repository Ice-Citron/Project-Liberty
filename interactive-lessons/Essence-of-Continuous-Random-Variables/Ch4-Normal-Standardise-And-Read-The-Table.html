The Normal: standardise, then read the table

Every Normal is the same bell. μ moves it and σ stretches it. No formula gives the area under it. So we change the ruler to z = (x − μ)/σ. Then one table of Φ answers every question.

Predict first
Read the question. Commit to an answer. Then open the card and check.
1 · The slide plots N(0, 4). What is σ?
σ = 2, not 4. The lecture writes N(μ, σ²). So the 4 is the variance. The bell is twice as wide as N(0, 1). Its peak is half as tall.
2 · Heights X ∼ N(170, 10²). Which is bigger: P(X ≤ 185) or P(Z ≤ 1.5)?
They are equal. 185 cm sits 1.5σ above μ. Standardising only relabels the ruler. The area does not move.
3 · The table has no negative z. How do you find Φ(−1.2)?
Use the mirror. The tail below −1.2 equals the tail above 1.2. So Φ(−1.2) = 1 − Φ(1.2) ≈ 1 − 0.885 = 0.115.
4 · What share of any Normal lies within μ ± 2.58σ?
About 99%. Φ(2.58) ≈ 0.995. So each tail holds about 0.5%. The middle holds 1 − 2 × 0.005 = 0.99.
5 · Y = eˣ with X ∼ N(0, 0.6²). Which is bigger: the median of Y or its mean?
The mean. The median is e⁰ = 1. The mean is e^(0.18) ≈ 1.197. The long right tail pulls the mean up.
Each number is rounded to 4 significant figures. The working uses full precision. So a last digit can differ by 1. In the table game this tab shows the full answer.
The pdf, piece by piece
f(x) = 1/(σ√(2π)) · e^(−(x − μ)²/(2σ²)) e^(−(x − μ)²/(2σ²)) the bell: 1 at x = μ 1/(σ√(2π)) makes the area 1
The exponent is the squared distance from μ in units of σ. So every Normal has the same shape. Only the ruler changes.
Why √(2π), a standard result
I = ∫ e^(−z²/2) dz I² = ∫∫ e^(−(x² + y²)/2) dx dy = ∫₀^2π ∫₀^∞ e^(−r²/2) r dr dθ (polar) = 2π · [−e^(−r²/2)]₀^∞ = 2π So I = √(2π). Then φ(z) = e^(−z²/2)/√(2π) has area 1.
One bell is hard to integrate. Two bells side by side make a round hill. Polar coordinates integrate the hill in one line.
Mean μ, variance σ²
E(X) = μ the bell is a mirror image about μ Put x = μ + σz: Var(X) = σ² ∫ z² φ(z) dz By parts, with φ′(z) = −z φ(z): ∫ z² φ(z) dz = [−z φ(z)] + ∫ φ(z) dz = 0 + 1 = 1
The slide says "it can be shown". These two lines show it.
Stretch and shift
Y = aX + b with a > 0: F_Y(y) = P(aX + b ≤ y) = P(X ≤ (y − b)/a) = Φ(((y − b)/a − μ)/σ) = Φ((y − (aμ + b))/(aσ)) So Y ∼ N(aμ + b, a²σ²). For a < 0 use 1 − Φ. Then σ_Y = |a|σ. a = 1/σ and b = −μ/σ give Z = (X − μ)/σ ∼ N(0, 1).
This is the Linear Transformations slide. Standardising is one special choice of a and b.
Reading the table
F_X(x) = Φ((x − μ)/σ) Standardising slide Φ(−z) = 1 − Φ(z) Using Table of Φ slide P(Z > z) = 1 − Φ(z) P(a < X ≤ b) = Φ(z_b) − Φ(z_a) P(|Z| ≤ k) = Φ(k) − Φ(−k) = 2Φ(k) − 1 Between rows z₀ < z < z₁ (Statistical Tables slide): Φ(z) ≈ Φ(z₀) + (z − z₀)/(z₁ − z₀) · (Φ(z₁) − Φ(z₀))
The straight line under-reads Φ where Φ curves down. For z ≥ 0 that is always. Between rows 0.1 apart the error stays below 0.0004.
Quantiles
P(X ≤ x_p) = p ⇔ x_p = μ + σ z_p where z_p = Φ⁻¹(p) Φ⁻¹(0.975) ≈ 1.96 95% inside μ ± 1.96σ Φ⁻¹(0.995) ≈ 2.576 99% inside μ ± 2.58σ
Read the table backwards. Find p in a Φ column. Take its z. Then undo the standardising.
Lognormal
Y = e^X, X ∼ N(μ, σ²), y > 0: F_Y(y) = P(e^X ≤ y) = P(X ≤ ln y) = Φ((ln y − μ)/σ) f_Y(y) = d/dy F_Y(y) = φ((ln y − μ)/σ) · 1/(σy) median = e^μ ln keeps the order mean = e^(μ + σ²/2) standard result, Ch 5
The 1/(σy) factor is the chain rule. It matches the pdf on the Lognormal slide.

The Essence
One shape, two dials. μ slides the bell. σ stretches it. The peak 1/(σ√(2π)) drops as σ grows. So the area stays 1.
The second number is the variance. N(0, 4) has σ = 2.
Every Normal is N(0, 1) on a new ruler. z = (x − μ)/σ counts σ-steps from μ. So F_X(x) = Φ(z).
The table only holds z ≥ 0. The mirror gives the rest: Φ(−z) = 1 − Φ(z).
Between two rows, draw a straight line. Linear interpolation is close enough for exams.
Landmarks. 95% lies within ±1.96σ. 99% lies within ±2.58σ.
Lognormal: eˣ stretches the right side. The median e^μ stays put. The mean moves right.
Mental-picture checklist
Honest caveats
The slide prints Φ(3.0) as .998. The exact value is 0.99865. To 3 dp that rounds to .999. The course sheet gives .9987.
The slide uses 2.58 and 2.576 for the same quantile. Φ(2.576) = 0.99500 and Φ(2.58) = 0.99506. Both round to 99.5%.
Interpolation is an approximation. Φ curves between rows. This page shows the size of that error in the Arithmetic tab.
68–95–99.7 is a standard rule. It is not on the slides. The slides give 1.96 and 2.58 instead.
Some books write N(μ, σ). This lecture writes N(μ, σ²). Check the notation first.
P(X < x) equals P(X ≤ x) here. A continuous X puts zero probability on a single point.
