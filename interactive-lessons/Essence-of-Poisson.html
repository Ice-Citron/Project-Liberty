Poisson: counting random events

Patients reach an emergency room at random times. On average λ arrive each hour. Count the arrivals in one hour. That count is X ∼ Poi(λ). Where does e−λλx/x! come from?

1 · λ = 3. Which count is most likely?
2 and 3 tie at 0.2240. p(3) = p(2) × 3/3. A ratio of 1 means a tie. This happens whenever λ is a whole number.
2 · λ = 0.1. What is P(X = 0)?
e−0.1 ≈ 0.905. A quiet window has chance e−λ. For small λ this is close to 1 − λ.
3 · Raise λ from 4 to 8. Does σ double?
No. σ grows from 2 to 2.83. σ = √λ. So twice the λ gives √2 times the σ. The spread grows slower than the mean.
4 · Compare Binomial(1000, 0.003) with Poi(3). How large is the largest gap?
About 0.00034. That is less than 0.2% of the tallest bar. Many chances with a tiny chance each act like a Poisson.
5 · 3 patients arrive per hour on average. What is the chance of no patient in 20 minutes?
e−1 ≈ 0.368. 20 minutes is 1/3 of an hour. So λt = 3 × 1/3 = 1. A quiet window has chance e−λt.

The slide definition
p(x) = e^(−λ) λ^x / x!, x = 0, 1, 2, …, λ > 0 μ = λ, σ² = λ, γ₁ = 1/√λ
X counts random events in one unit of time or space. The events occur at a constant rate. The slides state these facts. The sections below show why they hold.
From slots to the formula
n slots, each full with chance p = λ/n: P(X = x) = C(n, x) (λ/n)^x (1 − λ/n)^(n − x) = A · B · C · D with A = n(n − 1)…(n − x + 1) / n^x → 1 B = λ^x / x! stays C = (1 − λ/n)^n → e^(−λ) D = (1 − λ/n)^(−x) → 1 P(X = x) → e^(−λ) λ^x / x! as n → ∞
Hold x fixed and let n grow. A has x factors and each one tends to 1. C is the limit (1 + a/n)n → ea with a = −λ. D has a fixed power x. So it tends to 1 as well.
Why e−λ
P(X = 0) = P(every slot is empty) = (1 − λ/n)^n λ = 3: n = 10 0.7^10 = 0.02825 n = 100 0.97^100 = 0.04755 n = 1000 0.997^1000 = 0.04956 limit e^(−3) = 0.04979
A quiet hour needs every slot to stay empty. Finer slots make the product creep up to e−λ.
Why the bars sum to 1
Σ λ^x / x! = 1 + λ + λ²/2! + λ³/3! + … = e^λ Σ p(x) = e^(−λ) · e^λ = 1
The series is the Taylor series of eλ. So e−λ is the constant that makes the bars sum to 1. It is also the chance of a quiet window.
The ratio rule
p(x) e^(−λ) λ^x / x! ──────── = ──────────────────────── = λ / x p(x − 1) e^(−λ) λ^(x−1) / (x − 1)! x < λ: ratio > 1, so the bars climb x > λ: ratio < 1, so the bars fall mode = ⌊λ⌋; λ whole: p(λ − 1) = p(λ)
This rule is also the fast way to compute the pmf by hand. Start at e−λ. Multiply by λ/1, then λ/2, then λ/3.
Mean: the cancel trick
E[X] = Σ_{x≥0} x · e^(−λ) λ^x / x! = Σ_{x≥1} e^(−λ) λ^x / (x − 1)! = λ · Σ_{x≥1} e^(−λ) λ^(x − 1) / (x − 1)! = λ · Σ_{y≥0} p(y) = λ line 2 uses x / x! = 1 / (x − 1)! for x ≥ 1
Term by term, x · p(x) = λ · p(x − 1). The Arithmetic tab shows each pair with numbers.
Variance: one more cancel
E[X(X − 1)] = Σ x(x − 1) p(x) = λ² Σ p(x − 2) = λ² E[X²] = E[X(X − 1)] + E[X] = λ² + λ σ² = E[X²] − μ² = λ² + λ − λ² = λ
The Binomial gives the same answer. np(1 − p) = λ(1 − λ/n) tends to λ as n grows.
Skewness: two more cancels
E[X(X − 1)(X − 2)] = λ³ x³ = x(x − 1)(x − 2) + 3x(x − 1) + x, so E[X³] = λ³ + 3λ² + λ E[(X − μ)³] = E[X³] − 3μE[X²] + 2μ³ = λ³ + 3λ² + λ − 3λ(λ² + λ) + 2λ³ = λ γ₁ = λ / λ^(3/2) = 1/√λ
The Binomial skewness (1 − 2p)/√(np(1 − p)) with p = λ/n also tends to 1/√λ. The skewness page shows the cube-by-cube sums.
A longer or shorter window
rate λ per unit, window of length t: X ∼ Poi(λt), p(x) = e^(−λt) (λt)^x / x! mean = variance = λt
The input to the Poisson is always the mean count in the window.

The Essence
A Poisson counts dots in a window. The dots land at random times. They arrive at a constant average rate.
It is a Binomial with countless tiny slots. n slots with chance λ/n each give Binomial(n, λ/n). Let n grow and the pmf becomes e−λλx/x!.
e−λ is the chance of a quiet window. It is also the factor that makes the bars sum to 1.
Each bar is the last bar times λ/x. The bars climb until x reaches λ. Then they fall.
Mean and variance are both λ. So σ = √λ. The spread grows slower than the mean.
γ₁ = 1/√λ. The wall at 0 sits √λ standard deviations below μ. A big λ moves the wall far away. So the skew fades.
A longer window means a bigger λ. Rate λ over time t gives Poi(λt).
Mental-picture checklist
Honest caveats
Real arrivals rarely keep a constant rate. An emergency room is busier at some hours than others. Then the counts vary more than a Poisson predicts.
The slot story is a picture of the limit. A real slot can hold two arrivals. The limit n → ∞ makes that chance vanish.
λ need not be a whole number. Poi(2.5) has mean 2.5. No single hour has 2.5 arrivals.
A simulation wobbles. 1000 hours pin the mean down to about ±√(λ/1000). For λ = 3 that is about ±0.05.
