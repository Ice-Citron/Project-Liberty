Predict first
Read the question. Commit to an answer. Then open the card and check.
1 · You roll a fair die until a six shows. How many rolls does it take on average?
6 rolls. Each roll succeeds with p = 1/6. So μ = 1/p = 6. One six per six rolls in the long run means six rolls per six.
2 · No six in the first 10 rolls. How many more rolls on average?
Still 6. The die has no memory. After any number of failures the wait ahead is Geometric(1/6) again. A six is never due.
3 · Is x = 1 always the most likely value, for every p?
Yes. Each bar is (1 − p) times the bar before. So the bars only shrink. Even at p = 0.05 the first bar is the tallest.
4 · p rises from 0.1 to 0.9. Does γ₁ go up or down?
Up, from 2.003 to 3.479. Long waits get rare. But σ shrinks too. So each long wait sits more standard deviations above μ.
5 · Count failures instead of trials. Which of μ, σ² and γ₁ change?
Only μ. It drops by exactly 1. Y = X − 1 moves every bar left by 1. A shift does not change spread or shape.
Each number is rounded to 4 significant figures. The sums use full precision. So a last digit can differ by 1.
Decode the definition
X = min{ i | i ≥ 1, Xᵢ = 1 } = the index of the first trial that gives a 1 trial i: 1 2 3 4 5 … Xᵢ: 0 0 0 1 ? ↑ first 1, so X = 4
The set holds every index that shows a 1. min picks the smallest. Trials after the first 1 do not change X.
The pmf: one path per value
{X = x} = {X₁ = 0, …, Xₓ₋₁ = 0, Xₓ = 1} P(X = x) = (1 − p)(1 − p)…(1 − p) · p └─── x − 1 factors ──┘ = p(1 − p)^(x−1) by independence p(x + 1) / p(x) = 1 − p a constant ratio
A constant ratio between neighbours makes a geometric sequence. That is where the name comes from.
Why the bars sum to 1
Σₓ p(1 − p)^(x−1) = p (1 + q + q² + …) q = 1 − p = p · 1 / (1 − q) = p / p = 1 P(X > x) = P(X₁ = … = Xₓ = 0) = (1 − p)^x
Trial x stops a share p of the games still running. The rest carry over. No probability leaks away.
The mean, three ways
first step: E[X] = p · 1 + (1 − p) · (1 + E[X]) p E[X] = 1 → E[X] = 1/p tail sum: X = Σₖ 1{X ≥ k} counts each trial played E[X] = Σₖ P(X ≥ k) = Σₖ q^(k−1) = 1/(1 − q) = 1/p direct: Σₓ x q^(x−1) = d/dq Σₓ qˣ = d/dq 1/(1 − q) = 1/(1 − q)² E[X] = p · 1/p² = 1/p
First step. Spend one trial. With chance 1 − p it fails. Then the game starts over with a fresh copy of X.
The variance
E[X²] = p · 1² + (1 − p) · E[(1 + X)²] = p + (1 − p)(1 + 2E[X] + E[X²]) p E[X²] = 1 + 2(1 − p)/p → E[X²] = (2 − p)/p² σ² = E[X²] − μ² = (2 − p)/p² − 1/p² = (1 − p)/p² σ / μ = √(1 − p) so σ ≈ μ when p is small
The skewness
E[X³] = p + (1 − p) E[(1 + X)³] → E[X³] = (p² − 6p + 6)/p³ E[(X − μ)³] = E[X³] − 3μ E[X²] + 2μ³ = (p² − 6p + 6 − 3(2 − p) + 2)/p³ = (1 − p)(2 − p)/p³ σ³ = (1 − p)^(3/2) / p³ γ₁ = (2 − p) / √(1 − p) dγ₁/dp = p / (2(1 − p)^(3/2)) > 0 so γ₁ rises γ₁ → 2 as p → 0 so γ₁ > 2
The slide only says γ₁ is positive. The two lines at the bottom say more. Essence of Skewness draws every cube.
No memory
P(X > m + n | X > m) = P(X > m + n) / P(X > m) = (1 − p)^(m+n) / (1 − p)^m = (1 − p)^n = P(X > n) E[X | X > m] = m + 1/p
This property is why first-step analysis works. A failed trial leaves a fresh game.
Trials versus failures
Y = X − 1 supp(Y) = {0, 1, 2, …} p_Y(y) = p(1 − p)^y E[Y] = 1/p − 1 = (1 − p)/p Var(Y) = Var(X) = (1 − p)/p² γ₁(Y) = γ₁(X) = (2 − p)/√(1 − p)
These are the "minor corrections" that the slide's remark mentions. Only the mean moves.

The Essence
X is a waiting time. It counts trials up to and including the first success. So X starts at 1.
One path per bar. X = x needs x − 1 failures and then one success. Independence lets you multiply: (1 − p)^(x−1) p.
Each bar is (1 − p) times the last. That constant ratio makes a geometric sequence. Its sum is p / (1 − (1 − p)) = 1.
μ = 1/p is a rate turned over. A success rate of p per trial means 1/p trials per success. First-step analysis proves it in one line.
The spread matches the wait. σ/μ = √(1 − p). For rare successes σ is almost as large as μ.
Always right-skewed and never below 2. A wall at x = 1 blocks the left side. The right tail never ends.
The coin has no memory. After m failures the wait ahead is Geometric(p) again. A success is never due.
Mental-picture checklist
Honest caveats
Two conventions exist. This page and the lecture count trials. Some books count failures. A mean of 1/p means trials. A mean of (1 − p)/p means failures.
The slides stop at γ₁. The tail sum and first-step analysis are standard results. So is the no-memory property. They are not on these slides.
p must be above 0. At p = 0 the wait never ends. At p = 1 every game ends at trial 1. Then σ = 0 and γ₁ is undefined. So the slider runs from 0.05 to 0.95.
Simulated averages wobble. With n games the typical error is about σ/√n. At p = 0.25 and n = 1000 that is about 0.11.
